# Swarms API

Welcome to the Swarms API — the most advanced platform for building single
agents, reasoning systems, and enterprise-scale multi-agent swarms.

Whether you are creating a single intelligent agent or orchestrating thousands
of agents in complex workflows, Swarms provides the tools, infrastructure, and
runtime you need to bring your agents into production. Built on a
high-performance, Rust-powered agent runtime, the API exposes a comprehensive
suite of RESTful endpoints for the management, execution, and monitoring of
agents, swarms, and related resources.

## What you can build

- **Single agents** — deploy individual AI agents for focused tasks via `POST /v1/agent/completions`
- **Multi-agent swarms** — coordinate 3–10,000+ agents through 16+ architectures such as `SequentialWorkflow`, `ConcurrentWorkflow`, `HierarchicalSwarm`, `MixtureOfAgents`, and `GroupChat`
- **Reasoning agents** — advanced, premium-only reasoning systems (reasoning-duo, self-consistency, IRE, and more) via `POST /v1/reasoning-agent/completions`
- **Advanced workflows** — graph workflows, batched grid workflows, and batch processing at scale
- **OpenAI-compatible completions** — a drop-in replacement for the OpenAI API at `POST /v1/chat/completions`

## Platform benefits

- **Multi-agent architectures** — hierarchical, sequential, and parallel agent systems at scale.
- **Agent-to-agent communication** — protocols for seamless coordination and knowledge sharing across agents.
- **Optimized execution runtime** — a high-performance, concurrent runtime optimized for resource efficiency.
- **Enterprise security** — SOC 2, HIPAA, and GDPR-grade controls, multi-region availability, and transparent pricing.
- **Multiple model support** — choose from OpenAI, Anthropic, and Groq models, with automatic fallback support.

## API at a glance

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/health` | Health check |
| `POST` | `/v1/agent/completions` | Single agent completion |
| `POST` | `/v1/agent/batch/completions` | Batch agent completions (premium) |
| `POST` | `/v1/swarm/completions` | Swarm completion |
| `POST` | `/v1/swarm/batch/completions` | Batch swarm completions (premium) |
| `POST` | `/v1/chat/completions` | OpenAI-compatible chat completions |
| `POST` | `/v1/reasoning-agent/completions` | Reasoning agent completions (premium) |
| `GET` | `/v1/reasoning-agent/types` | List reasoning agent types |
| `POST` | `/v1/graph-workflow/completions` | Graph workflow (premium) |
| `POST` | `/v1/batched-grid-workflow/completions` | Batched grid workflow (premium) |
| `POST` | `/v1/auto-agent-builder/completions` | Generate agent configurations from a task |
| `GET` | `/v1/swarms/available` | List available swarm types |
| `GET` | `/v1/models` / `/v1/models/available` | List supported models |
| `GET` | `/v1/tools/available` | List available tools |
| `GET` | `/v1/agents/list` | List your agent configurations |
| `GET` | `/v1/swarm/logs` | Retrieve your API request logs |
| `GET` | `/v1/rate/limits` | View rate limits and usage |
| `GET` | `/v1/metrics/summary` | Usage metrics summary |
| `GET` | `/v1/usage/costs` | Current pricing details |
| `GET` | `/v1/account/credits` | Check your credit balance |
