# SDKs

Weldrr generates typed SDKs for the Swarms API. Each page covers installation,
client setup, and usage examples per language.

## Available clients

- [TypeScript SDK](/docs/sdk/typescript) — the generated TypeScript client (`swarm-sdk-typescript`) with typed methods for every public endpoint.
- [Python client](/docs/sdk/python) — the official `swarms-client` library (sync and async, powered by httpx).
- [Official client libraries](/docs/sdk/client-libraries) — the full catalog of community and official clients (Go, Java, Rust, and more).

All clients authenticate with the same credentials as the REST API: an API key
sent via the `x-api-key` header (or `Authorization: Bearer <key>`), against the
base URL `https://api.swarms.world`.
