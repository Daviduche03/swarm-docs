# Batch agent completions

Execute multiple agent completions concurrently using optimized thread pool
execution.

> **Premium tier required:** This endpoint is available only on Pro, Ultra, and Premium plans. [Upgrade your account](https://swarms.world/platform/account).

## Endpoint

`POST /v1/agent/batch/completions`

**Authentication:** Required — `x-api-key` header
**Rate limiting:** Subject to tier-based rate limits; max **10** agents per batch

## Request body

An array of `AgentCompletion` objects (max **10** per request). Each entry follows the
[AgentCompletion](/docs/reference/agent-completions#request-body) schema. Exceeding the
batch size returns a 400 error: `"ERROR: BATCH SIZE EXCEEDED - You can only run up to 10 batch agents at a time."`

## Response

**200** — `AgentBatchCompletionResponse`

| Field | Type | Description |
|-------|------|-------------|
| `batch_id` | `string` | Unique identifier for the batch |
| `total_requests` | `integer` | Total number of requests in the batch |
| `results` | `any` | The outputs generated by the agents |
| `execution_time` | `number` | Execution time of the batch |
| `timestamp` | `string` | Creation timestamp |

## Example

```bash
curl -X POST https://api.swarms.world/v1/agent/batch/completions \
  -H "x-api-key: $SWARMS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[
    {
      "agent_config": {
        "agent_name": "Analyst 1",
        "system_prompt": "You are a financial analyst.",
        "model_name": "gpt-4.1-mini"
      },
      "task": "Analyze Q1 financial results"
    },
    {
      "agent_config": {
        "agent_name": "Analyst 2",
        "system_prompt": "You are a market analyst.",
        "model_name": "gpt-4.1-mini"
      },
      "task": "Evaluate market trends"
    }
  ]'
```

```json
{
  "batch_id": "batch-abc123",
  "total_requests": 2,
  "results": [ { "job_id": "agent-1", "outputs": ["..."] }, { "job_id": "agent-2", "outputs": ["..."] } ],
  "execution_time": 3.4,
  "timestamp": "2026-08-14T19:11:02.018760+00:00"
}
```

## Errors

| Status | Cause |
|--------|-------|
| 400 | Batch size exceeded (more than 10 agents) |
| 401 | Missing or invalid API key |
| 403 | Free tier account (premium endpoint) |
| 422 | Schema validation failure |
| 429 | Rate limit exceeded |
