# Official client libraries

The Swarms API provides official client libraries across multiple programming
languages, enabling developers to integrate powerful multi-agent AI capabilities
into their applications with ease. The clients are designed for production use,
featuring robust error handling, comprehensive documentation, and seamless
integration with existing codebases.

## Available clients

| Language | Status | Repository | Description |
|----------|--------|------------|-------------|
| **Python** | Available | [swarms-client](https://github.com/The-Swarm-Corporation/swarms-client) | Production-grade Python client with comprehensive error handling, retry logic, and extensive examples |
| **TypeScript/Node.js** | Available | [swarms-ts](https://github.com/The-Swarm-Corporation/swarms-ts) | Modern TypeScript client with full type safety and Promise-based API |
| **Go** | Available | [swarms-client-go](https://github.com/The-Swarm-Corporation/swarms-client-go) | High-performance Go client optimized for concurrent operations |
| **Java** | Available | [swarms-java](https://github.com/The-Swarm-Corporation/swarms-java) | Enterprise Java client with Spring Boot integration |
| **Kotlin** | Coming soon | In development | Kotlin client with coroutines support |
| **Ruby** | Coming soon | In development | Ruby client with Rails integration |
| **Rust** | Coming soon | In development | Fast Rust client with memory safety |
| **C#/.NET** | Coming soon | In development | .NET client with async/await support |

## Getting started

- **Python:** see the [Python client guide](/docs/sdk/python).
- **TypeScript:** see the [TypeScript SDK guide](/docs/sdk/typescript).
- All clients authenticate with an API key against `https://api.swarms.world`.

## Generating your own client

Weldrr generates typed SDKs from the OpenAPI specification. The TypeScript SDK
for this project is published as `swarm-sdk-typescript` — see the
[TypeScript SDK page](/docs/sdk/typescript).
