# API reference

Every endpoint in the Swarms API, with authentication, request bodies, response
shapes, and error handling. The reference is organized one page per endpoint.

## Base URL

```
https://api.swarms.world
```

## Authentication

All endpoints require an API key. Send it in the `x-api-key` header
(`Authorization: Bearer <key>` is also accepted). Get a key at
[swarms.world/platform/api-keys](https://swarms.world/platform/api-keys).

## Common error responses

| Status | Meaning |
|--------|---------|
| 400 | Invalid input parameters or validation failures |
| 401 | Missing or invalid API key |
| 402 | Credit balance at or below the $1.00 minimum (billable endpoints) |
| 403 | Insufficient permissions or subscription tier (premium-only) |
| 422 | Schema validation failure (FastAPI `HTTPValidationError`) |
| 429 | Rate limit exceeded |
| 500 | Server-side processing error |

## Common schemas

- **AgentSpec** — the agent configuration object reused across endpoints. See [Agent completions](/docs/reference/agent-completions#agentspec).
- **SwarmSpec** — the swarm request body. See [Swarm completions](/docs/reference/swarm-completions).
- **HTTPValidationError** — `{ "detail": [{ "loc": [...], "msg": "...", "type": "..." }] }`
