# Getting started

The Swarms API lets you create and orchestrate AI agents for single-agent tasks
and multi-agent workflows. This section walks you through the essentials:
creating an account, authenticating, making your first request, and choosing the
right architecture for your use case.

## In this section

- [Quickstart](/docs/getting-started/quickstart) — build your first agent in under 5 minutes, including single-agent, swarm, batch, and tool-enabled examples.
- [Authentication](/docs/getting-started/authentication) — create an API key, configure it in your environment, and authenticate with the `x-api-key` or `Authorization: Bearer` header.
- [API architecture](/docs/getting-started/architecture) — the three agent tiers: individual agents, reasoning agents, and multi-agent swarms.
- [Swarm types](/docs/getting-started/swarm-types) — the multi-agent architectures you can drive through `POST /v1/swarm/completions`.

## Prerequisites

- Python 3.7+ or Node.js for JavaScript/TypeScript
- An [API key](https://swarms.world/platform/api-keys) from the Swarms platform

## The basics

Every request goes to the production base URL and must be authenticated:

- **Base URL:** `https://api.swarms.world`
- **Auth header:** `x-api-key: <your-api-key>` (the `Authorization: Bearer <key>` header is also accepted, which is what OpenAI SDK compatibility relies on)

Verify your connection with a health check:

```bash
curl -H "x-api-key: $SWARMS_API_KEY" https://api.swarms.world/health
```

```json
{ "status": "ok" }
```
